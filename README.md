# Riverbed 

> A system to receive webhooks from my [Pebble Index 01](https://repebble.com/index) and react

## Purpose 

The Pebble Index 01 has a feature to push all recordings/transcriptions to MCPs or a webhook endpoint, as detailed [here](https://help.repebble.com/en/articles/15724406-index-advanced-features-mcp-webhook].
